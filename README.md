A golden-hour travel poster for VELMORA, the Floating Isles — a chain of rock
islands drifting above a sea of clouds, crowned by a small lighthouse whose warm
lamp spills light across the sky. The poster is drawn 100% procedurally with
Pillow: a teal-indigo-to-amber gradient sky, a low glowing sun, waterfalls that
dissolve into luminous cream-and-gold cloud billows, and the place's name set in
huge letterspaced capitals.

## Run it

```bash
python3 main.py
```

`main.py` copies the repo's `entry.png` to the output directory (or
`$MAKEFUN_OUTPUT_DIR`), verifies its sha256, prints the digest, and exits 0.
Regenerate the image deterministically with `python3 draw_poster.py`.
